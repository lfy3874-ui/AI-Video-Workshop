手机图片转 MP4 网页项目
========================
功能：最多 8 张图片、每张 2-8 秒、逐张字幕、可选背景音乐，输出 MP4（H.264/AAC），画面 4:3（640x480）。

部署方式（Render）：
1. 将本文件夹内所有文件上传到一个 GitHub 仓库根目录。
2. 登录 Render，选择 New -> Blueprint。
3. 连接该 GitHub 仓库，Render 会读取 render.yaml。
4. 选择免费方案并部署。首次构建需要等待。
5. 部署成功后打开 Render 给出的 onrender.com 网址。
6. 手机上传图片和可选音乐，合成完成后下载 MP4。

注意：
- 免费 Render 服务闲置 15 分钟会休眠，首次访问需要唤醒。
- 免费实例只有 512MB 内存，可能无法处理特别大的图片或复杂任务。
- 服务器本地文件是临时的，服务重启/休眠后会丢失。
- 上传内容会经过云端服务器处理；不要上传敏感或隐私图片。
- 目前字幕按图片逐行对应；没有语音配音功能。
